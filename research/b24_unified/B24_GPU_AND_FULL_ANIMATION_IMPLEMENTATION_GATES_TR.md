## 0. Bugünkü cihaz gerçekleri: hedef sayı, performans ve neden
- 480×272 Vita paneli. C2 actual screenshot FPS ~12–14, `CPU=41–54ms`, `UP=29–30ms`. FPS 30 hedefi bir kare için ortalama en çok 33,3ms toplam duvar zamanı; 60 FPS 16,7ms. Bunlar **tasarım hedefi**, ölçülmüş ulaşılmış sonuç değildir. Ekran görüntüsündeki CPU+UP bile şimdiden 70ms civarı => GPU'ya geçiş, CPU framebuffer çizimi ve sık `SDL_UpdateTexture` maliyetini kaldırmalı.
- Sırf `glDrawElements()` çağrısı yazmak / vitaGL kütüphanesini linklemek, GPU renderer geçişinin tamamlandığı anlamına gelmez; gerçek GXM sahipli framebuffer, depth, shader, render swap, GPU geometry + anim suit, HUD ve texture kanıtı gereklidir.
- vitaGL resmi proje: https://github.com/Rinnegatamante/vitaGL; SDL2 Vita backend: https://wiki.libsdl.org/SDL2/README-vita. VitaGL, GL->sceGxm wrapper; VitaSDk mevcut `vitaGL` lib bağlanıyor ancak bu bugün hâlâ SDL Renderer'ın CPU raster framebuffer present yolunda kalıyor. **İkisini karışık iki bağımsız grafik context'i olarak aynı frame sunma.**

## 2. Tek gerçek GPU render owner / frame graph
1. Seçilen backend: **vitaGL / sceGxm** owning actual 3D framebuffer. `SDL_CreateRenderer` + `SDL_UpdateTexture` ownership path only in legacy fallback build configuration, **NOT in GPU game runtime**. SDL game controller can stay if compatible without SDL video renderer; otherwise `sceCtrlPeekBufferPositive` input adapter tested on real Vita.
2. `scene` pass: view/proj correct B17 Z-up, near clipping, opaque depth, batched original env indexed triangles, correct UV atlas, large mesh near/far and culling. `suit` pass: original 5 armored skinned IM2T geometries and properly timed IM2V streams, model root pitch/yaw/bank and transforms; same depth target.
3. `FX` pass: billboards/particles at per-frame correct original BDAE joint sockets; Stage1 2 feet only, Stage2 feet + 2 palms only; Stage3 RUSH additional **2 back** with original `Dummy_Back` center as anchor and nozzle outputs only if source verified/procedurally labelled.
4. `HUD` 2D orthographic overlay drawn once with real alpha/color, coherent crosshair actual aim ray; B17 debugging text and B22 visor not drawn twice. `pause` selectable menu overlay, only START activation, all UI options respond, actual game timer halt.
5. `swap` once: `vglSwapBuffers` (or sdk-advertised ownership). Frame timers: animation update, physics, scene setup, GPU submission, texture updates, present, FPS; don't misreport GPU times as CPU. VitaGL shader compiler `libshacccg.suprx` prerequisites on device checked.
6. Hard fail if model original 5 suit invisible, map original C1L1 not drawn, HUD not drawn, texture source missing, pause locks, or unplayable FPS. Native compilation success insufficient; real gameplay video/photographs in QA mandatory.
